# Finished code-alongs

Each folder is one code-along as it ended in class. The files inside sit at the same paths
they have in the app, so you can open yours and the finished one side by side, or copy a file
over yours to catch up.

| Folder | What it finishes |
|---|---|
| `1-bitcoins/` | The Bitcoin page: a route, a controller whose `index` does the work, a view that shows it. Then `?amount=` through `params`. |
| `2-show/` | Companies: `index` moves `Company.all` into the controller; `show` finds one company and its contacts; the index links to each company. |
| `3-create/` | Companies: `create` saves the form and redirects; the index links to the form. |
| `4-agent/` | Companies: `edit`, `update` and `destroy`, as the agent finished them from the commented steps in class. |

The posts form (the lab) is not here: it is yours, through your pull request. The written
solution is linked from Canvas after class.
